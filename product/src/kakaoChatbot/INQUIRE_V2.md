# Inquire V2

<br>

## LLM 필요성
1. 티커를 정확히, 게다가 야후파이낸스 스타일로 입력하는 것은 나쁨.
다음과 같이 검색할 수 있어야 함.

```
"삼성전자"
"삼전"
"애플"
"환율"
```

2. 유저들은 다음과 같은 질문들을 많이 함. 이것이 일반적으로 챗봇에 유저들이 기대하는 바. (피드백)

```
"가장 비싼 주식 뭐야?"
"시총 상위 10개"
"AI 기업"
"투자할만한 종목"
"저평가된 종목"
"배당주"
```

#### (A) 티커로 찾기

```
                  (2)
               asset 읽음?
          Y _______________ N
          |                 |
          |                 |
       return;             (4) - 캐싱 및 일괄처리
                         return;
```

#### (B) 자유발화에서 찾기

```
                  (5) - 웹검색 캐싱 (및 일괄처리?)
            ticker 어레이 찾음?
        Y ___________________ N
        |                     |
        |                     |
       (A) - iter           빈 어레이 => 응답(NotFound)
      응답(OK)                null => 응답(조회 목적이 아닌 발화)
```

### 응답

#### 1. 타임아웃

```
[TextCard]
desc - 아, "{검색어}" 에 대해 찾는데 시간이 오래걸리네요ㅠㅠ 거의 찾은것 같아요..!
button A - 그래, 계속 찾아봐! \ button B - 그만, 다른것 찾아줘.
```

동일 검색어에 타임아웃이 2번 반복되면,

```
[SimpleText]
죄송해요. 열심히 노력했지만 "{검색어}" 에 대해 찾을 수 없었어요...
```

<br>

#### 2. NotFound

```

```

<br>

#### 3. TooManyRequest


#### 4. OK

#### 5. 조회 목적이 아닌 발화

## 기타

### 챗봇
- 조회목적. 투자권유 않으며 책임지지 않음.
- 웰컴블록
- 폴백블록

### OpenAI api
- 응답 형식 지키지 않는 경우 => InternetServerError (일어나선 안되는데 일어날 수도 있는것 같음;; AI특;)
