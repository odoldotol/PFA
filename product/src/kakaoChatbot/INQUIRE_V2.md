## LLM 필요성
### 필요성 1.
티커를 정확히, 게다가 야후파이낸스 스타일로 입력하는 것은 나쁨.

```

"환율"
"금리"

```

### 로직

카카오톡 쳇봇 타임아웃 기준 내에 로직이 안정적으로 수행되는것을 기대하기 위해  
캐시를 읽는 IO(위 (2), (3) 에 해당)는 각 로직 단계에서 동기적으로 연결됨을 허용하나,  
HTTP IO(위 (4), (5)에 해당)는 불필요한 IO 가 발생할 지라도 몇몇 지점에서 병열로 수행할 필요가 있음.

특히, Market 에서 ticker 가 존재하지 않을떄 Notfound 를 던지기까지 IO 가 2000~4000 소요.  
이 IO 의 성능을 개선할 필요가 있으나, ((9) 를 새로 만들고 병열로 처리하여 약간의 개선을 함. 더 개선이 필요.)  
우선, 이 IO 를 최대한 피하고 (검색어가 티커타입인지를 잘 검사하는 것 만으로도 큰 효과 예상)  
로직을 중첩시켜 다른 IO 와 병열 처리를 허용하겠음.  

최후의 수단으로, 타임아웃 발생시 재시도를 유도하고  
재시도가 일괄처리 및 캐싱으로 이전 타임아웃 요청과 열결성을 가지도록 하겠음.

```
                                 (1) - 일괄처리
                       {검색어} 가 티커 타입에 속하나?
             Y ________________________________________ N
             |                                          |
             |                                          |
            (2)                                        (3)
         asset 읽음?                              ticker 어레이 찾음?
   Y ________________ N                     Y _____________________ N
   |                  |                     |                       |
   |                  |                     |                       |
응답(OK)              (3)                   (A) - iter              (B)
              ticker 어레이 찾음?           응답(OK)
            Y _________________ N
            |                   |
            |                   |
           (A) - iter          (4) - 캐싱 및 일괄처리
         응답(OK)               t(ms) 기다림
                               (B) 병열수행
                               (4) 또는 (B) 중 먼저 성공적으로 응답 할 수 있는 것을 응답
                               둘다 실패할때까지 기다리고 응답하는 것이 최악의 경우가 됨
```

#### (A) 티커로 찾기

```
                  (2)
               asset 읽음?
          Y _______________ N
          |                 |
          |                 |
       응답(OK)             (4) - 캐싱 및 일괄처리
                          응답(OK|Notfound)
```

#### (B) 자유발화에서 찾기

```
                  (5) - 캐싱 및 일괄처리
            ticker 어레이 찾음?
        Y ___________________ N
        |                     |
        |                     |
       (A) - iter         - NotFound
      응답(OK)             - Exception
                            - 검색어의 의도가 옳바르지 않음
                            - 시간에 민감한 성격
```
